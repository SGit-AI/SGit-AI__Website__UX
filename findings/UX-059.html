Findings / UX-059

A security prompt that asks you to approve a command it does not explain, and cuts off

OpenHighFailureClaude app (iPhone and iPad)

What we saw

The prompt says only "Bash wants to run:" above a box of raw shell: a variable holding a long path, then python3 reading a heredoc that rewrites a line in two files (tools/partition.py and tools/site_gate.py). Lines wrap mid-word ("newsro / om", "repos / itory") and the box is cut off with a fade halfway through the line that matters, the replacement string; nothing says whether it scrolls. Above it, a lock icon and its padding take about a quarter of the prompt. Below, two buttons, Deny and a filled black Allow once, which is the visually stronger choice. Nothing on the prompt says, in words, what the command does, which files it changes, whether it touches the network, whether it can be undone, or connects it to the agent's own explanation in the conversation behind the prompt ("team repo records need to move to records/").

Why it matters

The person is asked to make a security decision and given only code to make it with, partly hidden, on a phone. In practice the choice is to stop the work or to trust blindly, and every prompt like this teaches the habit of pressing Allow without reading, which defeats the point of asking. Here the command was harmless (a one-line edit to two files), but the prompt would have looked the same if it were not.

The fix

Lead with one line in plain words: "Edit 2 files in the newsroom repository: tools/partition.py and tools/site_gate.py (one line each)". Then the facts that decide it, as labels: reads, writes, deletes, network, outside the working directory, reversible. For an edit, show the diff, not the script that makes it. Link the agent's stated reason. Keep the full command one tap away, with real line breaks and no mid-word wrapping. Give Deny and Allow equal weight, or emphasise the safe choice. The short description already exists: the Bash tool asks the agent for a plain-words description of every command it runs, and the prompt does not show it.
