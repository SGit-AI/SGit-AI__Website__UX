Findings / UX-048

A vault app can load images and scripts from a site but cannot fetch its data

OpenLowGapdev.vault.sgraph.ai

What we saw

The host CSP is connect-src blob: data:. fetch() to newsroom.sgit.ai is refused although it sends access-control-allow-origin *, while <img> and classic <script src> from the same origin load.

Why it matters

Builders reasonably expect CORS-open data to be readable and discover otherwise in production; apps must snapshot data instead.

The fix

Snapshot the data into the vault (with SHA-256 in sources.json) and say in the UI which copy is shown. State the CSP where builders read about vault apps.
