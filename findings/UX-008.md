# Content is hidden until JavaScript runs

Open · medium severity · failure · newsroom.sgit.ai

## What we saw

The body starts at opacity 0 and only appears when a "ready" class is added, with a 1.6 s fallback.

## Why it matters

On a slow phone, or for any reader or agent that does not run the script, the page is blank.

## The fix

Render visible by default; animate only enhancements.
