Findings / UX-055

"Ask the article" has never run against a real on-device model

OpenLowGapNewsroom Design Lab

What we saw

The ask view uses Chrome's built-in model when present and a labelled extractive fallback otherwise. Only the fallback and a stub were tested; the model is absent in headless Chrome and likely in the vault frame.

Why it matters

The feature is shown to readers on a path nobody has seen work.

The fix

Test in a real Chrome with the model, or use sg.llm with an llm.chat grant; until then say "fallback" in the UI, as it does.
