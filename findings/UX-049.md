# Query strings break inside the vault host, so filters must live in the route path

Open · low severity · gap · dev.vault.sgraph.ai

## What we saw

Adding a query string to an app route breaks in the srcdoc frame.

## Why it matters

The usual way to make a filter linkable is not available; each app has to invent a path encoding.

## The fix

Encode filters in the path in a fixed order (desk, format, tag, series, month, q), as the findability vault does.
