# What good looks like

A finding says what is wrong; an exemplar shows something that already gets it right, so a fix can point at a working example instead of a description. Each one is measured like a finding (where, when, on what device), says **why** it works, and says honestly what it still does not do. They come from anywhere: our own sites, other sites, browsers, apps.

Each exemplar is linked from the findings it answers, and from the [principle](/principles/) it demonstrates. The source is [/data/exemplars.json](/data/exemplars.json).
