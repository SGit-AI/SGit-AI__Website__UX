# Browse the register

The same findings, indexed nine ways. Each value links to the [findings list](/findings/) filtered to it, and filters combine: `/findings/?problem=unexpected-movement&visibility=intermittent` is a link you can send. The vocabularies live in [/data/taxonomy.json](/data/taxonomy.json) and grow only when a finding needs a value that is not there yet.
