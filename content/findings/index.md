# Findings

Every UX failure and gap in the register, open first, then by severity. A **failure** works against the reader; a **gap** is something the reader needs that is not there. Each status says when it was last checked, and on which version: nothing here claims to be current beyond that.

{{findings-register}}

Browse the same register [by product, problem, visibility, recommendation and principle](/browse/).

The register is one file, [/data/findings.json](/data/findings.json). This page, every finding page and every count on the site are generated from it. To add a finding, see [the method](/method/#filing-a-finding).
